# External Data Flows

This document records every third-party integration, what data leaves the server, and which workspace/feature controls gate it.

| Provider / Feature | Interface | Outbound Data | Gating Controls | Local Dev / Test Behavior |
| --- | --- | --- | --- | --- |
| **Anthropic Claude** (`Catch me up` / `/summarize`) | `services/summaryService.js` | Room message transcript wrapped in `<untrusted_chat_transcript>` XML tags (with prompt-injection system guard) | `aiSummaries` feature flag + per-user rate limit (5/hr) + room membership | Mock Anthropic client in tests |
| **Giphy** (`/giphy <query>`) | `services/providers/gifProvider.js` | Search query string only (never message history or user PII); `rating=pg` enforced | `slashCommands` feature flag + `workspace.settings.allowExternalProcessing` + per-user rate limit (10/min) + CSP `img-src` allowlist | `createMockGifProvider()` used in tests and when `GIPHY_API_KEY` is unset |
| **Outgoing Webhooks** (`dispatchOutgoingEvent`) | `services/webhooks/outgoingDispatcher.js` + `ssrfGuard.js` | Signed JSON event payload (`eventId`, `deliveryId`, `event`, `workspaceId`, `roomId`, minimal message/member data) | `outgoingWebhooks` feature flag + workspace/room scoping + HTTPS-only + SSRF IP/redirect guard | Delivered via atomic `OutgoingDeliveryJob` queue (Redis/BullMQ optional) |
| **Semantic Search Embeddings** (`embeddingService.js`) | `services/providers/embeddingProvider.js` | Message text snippet (max 2000 chars) | `semanticSearch` feature flag + `workspace.settings.allowExternalProcessing` + room membership filter | Deterministic 64-dim `createMockEmbeddingProvider()` in tests and local dev |
| **Workspace Q&A / RAG** (`POST /api/v1/ai/ask`) | `services/ai/askService.js` | User question + top-5 accessible message snippets wrapped in `<untrusted_context>` | `aiAsk` feature flag + `workspace.settings.allowExternalProcessing` + room membership filter + 15/hr rate limit | `createMockAskLlmProvider()` in tests and local dev |
| **TURN / WebRTC ICE** (`GET /api/v1/calls/ice-servers`) | `services/providers/turnProvider.js` | User ID hashed into ephemeral `<expiry>:<userId>` HMAC-SHA1 credential (300s TTL); media streams P2P/TURN encrypted (DTLS-SRTP) | `calls` feature flag + JWT auth | `createMockTurnProvider()` (STUN only) when `TURN_SHARED_SECRET` is unset |
| **Web Push & Email Digests** (`notificationDispatcher.js`) | `providers/pushProvider.js` & `providers/emailProvider.js` | Encrypted push keys (`keysEnc`), notification title/body, or unread room digest summary | `notifications` feature flag + `workspace.settings.allowExternalProcessing` + user `dnd` / `globalMute` | `createMockPushProvider()` & `createMockEmailProvider()` in tests and local dev |
| **Billing & Checkout** (`routes/billing.js`) | `services/providers/paymentProvider.js` | `workspaceId`, `plan`, `userId` for checkout session; inbound signed Stripe webhook events | `billing` feature flag + owner-only checkout + HMAC `Stripe-Signature` (`300s` replay window) + `BillingEvent` dedupe | `createMockPaymentProvider()` in tests and local dev |
